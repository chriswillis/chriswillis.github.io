COLOR RAMP V2

1. Extract this ZIP archive into a folder on your computer.
2. Open the color-ramp-v2 folder.
3. Double-click index.html to open the tool in your web browser.
   Keep index.html, the JavaScript/CSS files, and the assets folder together.

No installation or build step is required. Palette calculations run in your
browser. Google Fonts can load when you are online; system fonts work offline.

SAVE YOUR WORK
- Save project downloads your complete editable palette as a .ramp.json file.
- Open loads a saved project, including shapes, color edits and preview choices.
- Export palette > Download saves CSS, Tailwind or design-token colors.

The local copy and the hosted site have separate browser storage. To move your
current work to this copy, first click Save project on the hosted site, then
click Open in the local copy and choose that downloaded .ramp.json file.

Some browsers restrict automatic clipboard access for local files. Export
downloads and project save/open remain available.

The color engine and reference data come from Chris Willis's Palette DNA.
Each reference palette retains its author's source and license metadata.
