BRING YOUR OWN DNA
Start with a palette you trust.
Use at least four colored ramps sharing three or more step names. Importing happens in your browser.

  
A little structure. More freedom.
Start with your color. Palette DNA learns the lightness and colorfulness of an authored reference palette and builds a brand ramp around your input.
Make the shape yours. Custom mode resamples that ramp into 3–32 stops and remaps its lightness. Colorfulness is carried as a share of the available gamut at each new lightness. Even spacing uses equal OKLCH lightness increments.
Keep your anchor. The brand-color lock keeps the generated input anchor. A range that excludes it is expanded with a visible notice. Reference gamut or fit mode may adjust the initial input; any difference is reported.
Control the scope. All ramps share your default shape. Choose “This ramp only” to add an override. Reference default preserves the authored count and labels. A changed count uses neutral labels 01, 02, and so on.
See it in context. Dark mirrors the light preview’s positions from the opposite end of each ramp: 50 pairs with 950, 100 with 900, and so on. Surface, text, border and accent roles follow this rule, including custom stop counts. This changes previews; exported ramp colors stay the same. Color-vision previews use Machado severity-1 matrices in linear sRGB.
Keep the whole project. Save/open retains palette choices, edits, shape settings and preview choices. Token exports contain colors for implementation.
Color engine and reference data from Chris Willis’s Palette DNA. Each reference palette retains its author’s license.
