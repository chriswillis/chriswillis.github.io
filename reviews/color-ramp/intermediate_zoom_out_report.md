Specify supported preservation and behavior outside it. A qualified mode is a legitimate smaller choice only if changed, substituted and omitted inputs and export limits are explicit. Counterargument: an unresolved choice is acceptable in a review backlog, but cannot count as a fully specified repair.

## Major — Persistence failure handling must include removal

The addition contract in plan §2 omits removal. The handler at color-ramp.html:1482–1486 mutates PALS, changes selection, and uses the same error-swallowing saveUser. A denied write can make a removed palette return on reload. Apply the same transaction rule: retain prior list/selection on persistence failure. Counterargument: original findings concern import, but this is the same small state boundary and avoids an incomplete repair.

Do not retain confidence-colored result badges derived from unsupported predictions. Useful reference evidence need not retain the current predictive calculation.
