# Accepted repairs — 1 November 2026

Implemented locally in color-ramp.html after acceptance of the review. No commit or deployment.

## Decisions and changes

- Adapted the sister page's complete-value parser, all-coordinate validation, alpha parsing, complete import collectors, and null-prototype collections. Direct input requires opaque colors; translucent imported entries retain explicit skip-with-note behavior.
- Invalid or empty drafts leave the committed ramp visible with a last-valid-result notice and disable Copy immediately. Correcting the input restores copying. Inline errors name supported input forms.
- Selected the qualified approximation contract: **Through color** replaces **Stays exact**. Near-reference recognition no longer triggers the authored-ramp identity branch unless the measured difference is below 1e-7 in ΔE OK ×100. Every input is described as preserved, approximated with its difference, or omitted. Neutral substitution and the retained second input in a near-lightness collision are disclosed. No new numerical algorithm was introduced, and gamut-limited input may still change.
- Removed anchored-result probability estimates and confidence badges, including marketing/help claims. Family ordering now uses a geometric segment field independent of confidence data. Automatic unused hold-out calculation is no longer scheduled. The existing engine's research routines remain available; source extraction is deferred.
- Added versioned `#r2=` JSON state containing original c1/c2 strings, palette ID, mode, name, and format. A valid available-palette v2 link takes precedence over local state. Invalid v2 or unavailable palette links retain valid local/default settings and explain fallback. Legacy links still load; when a legacy hex link matches locally stored original seeds, the precise local strings are preserved. A subsequent save migrates to v2. Imported palette data itself remains browser-local and is not embedded in links.
- Import readiness invalidates immediately on text/name edit, file selection, example insertion and close. Commit revalidates current fields. File callbacks have request ownership and are ignored after newer edits, selection or close. Add/remove persist successfully before changing the selected palette/list. Storage failure leaves the committed state unchanged and displays an error.
- Export formats are ordinary pressed buttons. Their state and Copy success lookup use the same attribute. Upload has a native button; modal close returns focus to the palette selector. Color controls have a focus-within outline. Replaced the broad result live region with focused invalid-draft status. Added persistent export gamut/precision guidance and made anchor/contrast legends describe measured output without an exactness/pass guarantee.
